# Bestiary frames — v1

Generated with the built-in image tool using the imagegen skill. Centers and exterior retain generated alpha. Runtime uses UV bounds to align the visible square without resampling the sources.

## normal

Asset: assets/ui/content_icons/frames/bestiary/normal_v1.png

Prompt:

Use case: stylized-concept. Asset type: transparent fantasy RPG portrait frame overlay, one square frame only. Primary request: thin plain dark antique yellow gold square border, perfectly simple straight sides, 1.3% of square width thickness, square mitered corners, absolutely no ornaments. Style: hand-painted detailed dark medieval fantasy game UI, worn metal, restrained highlights, fits dark stone and parchment menus. Composition: flat front view, 1024x1024 square canvas. Frame outer square precisely from 4% to 96% on BOTH axes; entire center completely empty and genuinely transparent, outside the frame transparent too. No solid backing inside, no portrait, no letters, no words, no icons, no jewels, no shadow beyond the object, no perspective, no extra frame. Corners must not intrude more than 10% into the empty portrait area. Crisp clean alpha silhouette.
