PROCESSING
Recorded swish/foley/impact layers; labeled speed/pitch edits, gain and timing changes.
Mono 44.1 kHz / 16-bit WAV, peak matched to approximately -12 dBFS, 5 ms end fade.
RS examples contain five strokes; the upgraded runtime version will require seven.
EB examples contain three impacts at 180 ms spacing; the upgraded version will require four.
Ability timing, voice limits and in-game mixing are not finalized by these offline examples.
The exact recording names are listed in SECENEKLER.txt; preparation code retains each edit/layer.
